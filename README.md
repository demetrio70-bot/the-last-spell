# Oraculum Expanded & Other Improvements

A collection of mods for **The Last Spell** that expands Oraculum progression, improves game balance, and adds quality-of-life features while staying close to the original experience.

## What's included

- **Oraculum upgrades:** More progression options for item and attribute rarity, attribute rerolls, shop refreshes, shared experience, ballistas, and corpse generation.
- **Balance improvements:** Adjustments to item and attribute weights.
- **Quality of life:** Shop sorting, ballista kill reports, and a color-vision accessibility overlay.

## Installation

**Requirement:** BepInEx 5 (64-bit) installed for *The Last Spell*.

1. Click **Code → Download ZIP** on this page and extract the ZIP file.
2. Open the extracted `plugins` folder.
3. Copy the `.dll` files into your game's `BepInEx/plugins/` folder.
4. Launch the game.

**Steam users:** To find the game folder, right-click *The Last Spell* in your Library and select **Manage → Browse local files**.

**Uninstall:** Remove the corresponding `.dll` files from `BepInEx/plugins/`.

# Oraculum Expanded & Other Improvements

A collection of mods for **The Last Spell** that expands Oraculum progression, improves game balance, and adds quality-of-life features while staying close to the original experience.

## What's included

- **Oraculum upgrades:** More progression options for item and attribute rarity, attribute rerolls, shop refreshes, shared experience, ballistas, and corpse generation.
- **Balance improvements:** Adjustments to item and attribute weights.
- **Quality of life:** Shop sorting, ballista kill reports, and a color-vision accessibility overlay.

### Included plugins

| **DLL** | **Description** |
| --- | --- |
| `AttributeRarity.dll` | Improves Oraculum attribute-rarity progression |
| `AttributeRerolls.dll` | Expands attribute reroll options through Oraculum upgrades |
| `AttributeWeight.dll` | Rebalances the weights of individual attributes |
| `BallistaKillReport.dll` | Displays ballista kill information |
| `BallistaUpgrade.dll` | Adds a new level to the Oraculum ballista upgrade |
| `FairCorpses.dll` | Adds new Oraculum upgrades for corpse generation |
| `ItemRarity.dll` | Improves Oraculum item-rarity progression |
| `ItemWeight.dll` | Rebalances item weights |
| `ProtanDangerOverlay.dll` | Adds a color-vision accessibility overlay |
| `SharedExperienceBalance.dll` | Adds Oraculum progression for shared experience |
| `ShopRefreshPricing.dll` | Adds Oraculum progression for shop refresh costs |
| `ShopVisualSort.dll` | Adds visual category sorting to the shop |

**Don't want a feature?** Simply delete its corresponding `.dll` file from the `BepInEx/plugins/` folder.

## Installation (Windows)

**Recommended — Complete package (BepInEx included):**

1. [Download the Complete ZIP](downloads/Oraculum_Expanded_Complete.zip).
2. In Steam, right-click *The Last Spell* → **Manage → Browse local files**.
3. Extract the ZIP contents directly into the game folder.
4. Launch the game.

**Already have BepInEx 5 installed?** Download the [Plugins Only ZIP](downloads/Oraculum_Expanded_Plugins_Only.zip) and extract it into the same game folder instead.

**Note:** Subscribing on Steam Workshop does not install these DLLs; download one of the ZIP files above.

**Uninstall:** Remove the corresponding `.dll` files from `BepInEx/plugins/`.
